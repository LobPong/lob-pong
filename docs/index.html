Lob Pong Rules

Lob Pong is a doubles table tennis game. Partners can set up each other and play a lob for extra points.

The ITTF rules for doubles table tennis apply. Lob Pong adds four changes: lobs (section 2), the serve-edge rule (3.1), service rotation every 5 points (3.2), and the Three-Strike rule at game point (6.4).

Each animation below shows one rule. You can pause it, replay it, or drag the timeline.

Terms

  • Ball-strike: Any contact between a player and the ball.
  • Strike: A penalty count against a team. A strike is not a ball-strike.
  • Return: The ball-strikes one team makes after the ball crosses the net, until the ball crosses back over the net or the point ends. The serve is not a return.
  • Setter: The first player to make a ball-strike on a return.
  • Spiker: The setter's partner. The spiker makes the second ball-strike on a return. A one-hit return has no spiker.
  • Lob: A return in which both the setter and the spiker make a ball-strike.
  • One-hit return: A return with one ball-strike.
  • Game point: A team is at game point when one more point would win the game.
  • Player labels: Team A's players are A1 and A2. Team B's players are B1 and B2.

Service order

3.1 If a valid serve hits the table edge, the server's partner must make a ball-strike, or the receiving team scores a point.

  1. 3.1.1 If the server's partner makes a ball-strike, the rally counts as a lob.
  2. 3.1.2 If the server's partner does not make a ball-strike, the receiving team scores a point.

3.2 Service changes every 5 points.

  • Count the total points scored in the game. Points worth more than 1, such as lobs, count in full.
  • Divide the total by 20 and use the remainder:
    • 0 to 4: Server 1
    • 5 to 9: Server 2
    • 10 to 14: Server 3
    • 15 to 19: Server 4
  • The servers take turns between the teams in this order:
    • Server 1: A1.
    • Server 2: The Team B player who received Server 1's serve (B1 or B2).
    • Server 3: A2, the partner of Server 1.
    • Server 4: The other Team B player, the partner of Server 2.
  • The teams choose Server 1 for each game by any method they agree on.
  • A point that does not count under 6.4.1 is not added to the total. The score does not change, and the rally is replayed.

Lobs and lob scoring

2.1 Each player may make one ball-strike per return. The exception is the first return after the serve. On that return, only the receiver may make a ball-strike.

2.2 The setter may return the ball directly. Or the setter may make a ball-strike that lets the spiker return the ball to the opponents' side of the table.

2.3 During a lob, one hand of the spiker may touch any part of the table.

2.4 Lob scoring:

  1. 2.4.1 A lob that scores directly after a one-hit return is worth 2 points.
  2. 2.4.2 A lob that scores after a lob by the opponents is worth N + 1 points. N is the number of consecutive lobs by both teams since the last one-hit return, including the scoring lob.

    Example: The serving team lobs at the first legal chance, after the receiver's return. The receiving team lobs back and scores. There are 2 consecutive lobs, including the scoring lob, so the scoring lob is worth 3 points.

Offside

5.1 The offside line is the back edge of the table on the spiker's own end. It is parallel to the net and extends out from the table indefinitely.

5.2 When the spiker makes a ball-strike, the spiker's entire lower body must be behind the offside line. "Behind" means on the side of the line away from the table. If the spiker's lower body is not behind the line, the opposing team scores a point.

  1. 5.2.1 The lower body is the part of the body below the height of the tabletop surface.
  2. 5.2.2 The spiker may lean over the offside line with the upper body.

Three-Strike (Filippini) rule

6.1 A match is best of 3 games. Each game is played to 21 points. Players may agree on different point targets or a different number of games before a match.

6.2 The winning team must lead by at least 2 points.

6.3 The winning team's last return must be a lob. A point that is not a lob cannot win the game. See 6.4.

6.4 Three-Strike (Filippini) rule

  1. 6.4.1 If a team at game point scores a point that is not a lob, the point does not count. The opposing team receives a strike. The rally is replayed with the same server.

    Example: Team A leads 20-15. Team A scores a point that is not a lob. The score stays 20-15, the rally is replayed with the same server, and Team B receives 1 strike.

  2. 6.4.2 When a team scores a counting point, the strikes of both teams are reset to zero.
  3. 6.4.3 A team with 3 strikes loses the game.
  4. 6.4.4 When any team reaches game point, all four players must say aloud, before the next serve: "The Three-Strike (Filippini) rule is in effect."
