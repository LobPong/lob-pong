# Lob Pong

A better way to play ping pong.

Lob Pong is a doubles variant of table tennis. It uses the ITTF doubles rules, with the changes in [RULES.md](RULES.md).

## What is different

- **Lobs.** On a return, one player sets the ball and their partner (the spiker) hits it over the net. Lobs score more points. See [RULES.md](RULES.md), section 2.
- **Serve edge.** If the serve hits the table edge, the server's partner must make a ball-strike, or the receiving team scores. See section 3.1.
- **Service rotation.** Service changes every 5 points. See section 3.2.
- **Three-Strike rule.** A Three-Strike (Filippini) rule applies at game point. See section 6.4.

## Scoring at a glance

- A match is best of 3 games. Each game is played to 21 points.
- Players may agree on different point targets or a different number of games before a match.
- The winning team must lead by at least 2 points.
- The winning team's last return must be a lob. See section 6.3.
- A lob after a one-hit return scores 2 points. A lob after consecutive lobs scores more. See section 2.4.
